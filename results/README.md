# Results Directory

This directory stores experimental results generated by the simulation system.

## Directory Structure

- `runs/` - Individual simulation run results
- `comparisons/` - Strategy comparison results
- `ablation/` - Ablation study results
- `robustness/` - Robustness test results
- `finals/` - Final presentation/demo results

## What Should Be Committed

- `README.md` - This file
- Summary/metadata files that document important findings
- Example configuration snapshots

## What Should NOT Be Committed

- `results/runs/**` - Individual run data (plots, CSV records, etc.)
- `results/ablation/**` - Ablation study outputs
- `results/comparisons/**` - Comparison outputs
- `results/robustness/**` - Robustness test outputs
- `results/finals/**` - Final outputs
- Any large binary files (PNG, MP4, etc.)

## Git Ignore Rules

All result subdirectories are ignored by default in `.gitignore`, with the following exceptions:
- Empty directory placeholders (via negation rules)
- This README.md file

Result files should be stored externally (e.g., cloud storage) if long-term preservation is needed.
